## Featured Project

### SnapClass — AI-Powered Smart Classroom Attendance System

A deployed classroom attendance application combining **Face Recognition and Voice Recognition** to automate student attendance and classroom management.

**Tech Stack:**
Python · Streamlit · Supabase · Dlib · Scikit-learn · Resemblyzer · Librosa · NumPy · Pandas

#### Features

* **Dual-Mode Biometric Attendance** — Face Recognition and Voice Recognition for student identification.
* **Biometric Student Enrollment** — Registration using facial and voice data.
* **AI-Based Student Identification** — Uses biometric embeddings to identify registered students.
* **QR & Share-Link Enrollment** — Students can join subjects through a generated QR code or shareable link.
* **Automatic Subject Enrollment** — Valid class links trigger the subject enrollment workflow.
* **Teacher Dashboard** — Create subjects, manage students, and monitor attendance.
* **Student Dashboard** — View enrolled subjects and attendance records.
* **Attendance Management** — Review attendance and manually correct records when required.
* **Cloud Database** — Student, subject, enrollment, and attendance data managed through Supabase.

**Live Demo:**
[Launch SnapClass →](https://snapclass-main111.streamlit.app/)
