## Featured Project

### SnapClass — AI-Powered Smart Classroom Attendance System

**An end-to-end, deployed attendance platform combining Face Recognition and Voice Recognition with automated classroom workflows.**

**Tech Stack:** Python · Streamlit · Supabase · Dlib · Scikit-learn · Resemblyzer · Librosa · NumPy · Pandas

**What I Built**

* **Dual biometric attendance** using Face Recognition and Voice Recognition.
* **AI-based student identification** using facial and voice embeddings.
* **Biometric student enrollment** with facial and voice data.
* **QR and share-link based subject enrollment** for quick classroom joining.
* **Automatic enrollment workflow** from shared subject links.
* **Teacher dashboard** for subject creation, student management, and attendance monitoring.
* **Student dashboard** for enrolled subjects and attendance tracking.
* **Attendance management** with attendance review and manual correction.
* **Supabase integration** for cloud-based student, subject, enrollment, and attendance data.
* **End-to-end deployment** using Streamlit Cloud.

**Live Demo:**
[Launch SnapClass →](https://snapclass-main111.streamlit.app/)
